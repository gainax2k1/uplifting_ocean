# uplifting_ocean

Narrative therapeutic cozy-game  for Uplifting Game Jam #9

 https://itch.io/jam/uplifting-game-jam-9



# How to play:
- Click on the dialog boxes to progress through the store
- For each section, there's a guided task for you to perform IRL, such as breathing excercises.
- Take your time! These are all things I use myself to help with anxiety. <3
